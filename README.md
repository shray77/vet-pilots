# vet-pilots

Полигон пилотных запусков ML-инструментов экосистемы `shray77` — эксперименты перед промоушеном
в продуктивные репозитории. Каждый пилот: реальная модель + реальные данные экосистемы +
артефакты + честные оговорки. Всё CPU-only, без GPU.

---

## Пилот 1: TSPulse — аномалия недели на суточном ряду вспышек

**Модель:** [ibm-granite/granite-timeseries-tspulse-r1](https://huggingface.co/ibm-granite/granite-timeseries-tspulse-r1)
(1M параметров, revision `main` = AD-вариант `tspulse-hybrid-allhead-512-p8-r1`), CPU-инференс.
API — официальный ноутбук granite-tsfm `tspulse_anomaly_detection.ipynb`: двойная реконструкция
(time + fft), агрегация 64/max, сглаживание 8.

**Данные:** `vet-heatmap/outbreaks.json` (WAHIS + РСХН/ФСВПС), 2758 вспышек 2005–2026.
Суточный ряд последних 6 лет = 2192 точки (требование TSPulse AD ≥1536–2048 точек).
Среднее 1.2 вспышки/день, максимум 24.

**Результаты:**
- **Топ-аномалия 6 лет — майская волна бешенства 2026** (score 0.94): кластер 04–09.05.2026,
  до 8 вспышек бешенства в сутки (Алтайский, Красноярский край, Смоленская, Амурская обл.) —
  классическая весенняя лисичья волна, физично.
- **Аномалия недели (09–15.10.2026): «повышенный фон»** — mean score 0.395, max 0.443
  (85–88 перцентиль истории), ни одного дня выше порога 0.6. Содержательно: 12 вспышек
  14.10 (бешенство 5, лейкоз КРС 3, трихинеллёз 2) — осенний подъём бешенства, согласуется
  с сезонностью.
- Модель также корректно поймала **ступеньку уровня данных** (пауза источника в конце 2025 →
  скачок уровня в 2026) — полезный побочный эффект: пайплайн ловит и реальные волны,
  и артефакты сбора данных.

**Оговорки:**
- Дни-«нули» рядом с кластером наследуют высокий score из-за агрегации 64/max — это поведение
  официального пайплайна, не баг.
- Ранние годы (2005–2019) в ряд не включены: исторический слой ФСВПС кураторски неровный.
- Ряд короткий для сезонной модели (6 лет) — весной 2027 стоит переобучить окно и сравнить.

**Артефакты:** `anomaly_chart.png`, `anomaly_scores.csv` (2192 строки),
`pilot_summary.json`, `vet_outbreaks_daily.csv`, `scripts/pilot_tspulse.py` (воспроизводимо).

**Следующий шаг (если пилот признаём):** weekly-джоб в GitHub Actions (паттерн vet-digest-llm),
результат — в дайджест недели и в ВетХаб карточкой «аномалия недели».
